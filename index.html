⚙️ Yapay Zekâ Ayarları

Gerçek yapay zekâ yanıtları için bir API anahtarı gir. Anahtarın yalnızca bu tarayıcıda saklanır, hiçbir sunucuya gönderilmez.

Gemini anahtarı almak için: aistudio.google.com → “Get API key”

Boş bırak → varsayılan model kullanılır

OpenAI uyumlu /v1/chat/completions uç noktası olmalı. Örn: Ollama → http://localhost:11434/v1, LM Studio → http://localhost:1234/v1

💾 Veri Yedeği

Tüm uygulama verini (rehber arşivi, adımlar, sınıf gönderileri, rozetler, geri bildirimler, özel bileşenler) tek dosyaya al; başka bilgisayarda geri yükle.

🏷️ Malzeme Fiyat Kataloğu

Okulunun kataloğu farklı mı? Her satıra Parça adı: fiyat (USD) yaz — rehber tablolarında katalog fiyatının yerine geçer. Örn: Arduino Uno: 8, SG90 servo motor = 2,75

Toplam aşılırsa malzeme tablosunda ⚠️ kırmızı uyarı çıkar. 0/boş = kapalı.
Sınıf raporu mevcut × proje maliyetiyle tüm sınıfın bütçe planını gösterir. 0/boş = kapalı.
